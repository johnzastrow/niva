# Free geospatial data downloadable with `wget`

This report catalogs free geospatial datasets that can be downloaded directly with a URL and `wget`, without authentication, with emphasis on sources useful for the northeastern United States while still including global and U.S.-wide coverage.[cite:5][cite:16][cite:2] The focus is on sources that expose direct downloadable files or predictable URL patterns rather than portals that require API keys or login.[cite:5][cite:13][cite:30]

## Coverage and format notes

The sources below collectively cover many common GIS formats including Shapefile, GeoJSON, KML/KMZ, CSV, GeoPackage, File Geodatabase, OSM PBF, GeoTIFF, and LAS/LAZ.[cite:6][cite:7][cite:10][cite:13] In several cases, the landing page is the stable source while the final file URL follows a repeatable pattern that can be scripted with `wget`.[cite:5][cite:22][cite:25][cite:30]

## Notable source groups

Natural Earth provides small, direct ZIP downloads for global cultural and physical vector layers and small-scale rasters, making it one of the easiest sources to script.[cite:4][cite:11] TIGER/Line from the U.S. Census Bureau provides nationwide administrative and transportation layers as direct Shapefile ZIPs, including Maine and the broader Northeast.[cite:5][cite:22][cite:25] Maine GeoLibrary and other state GIS portals add higher-value local coverage for parcels, orthoimagery, transportation, and elevation, though some resources are exposed through ArcGIS Hub dataset pages rather than a single static index.[cite:16][cite:2]

## GitHub list additions

Several GitHub “awesome” and curated GIS lists were checked to expand the catalog beyond the first pass.[cite:32][cite:40][cite:41] In particular, Cornell GIS data sources adds references to New York state GIS, USGS National Map, NOAA Digital Coast, OSM/Geofabrik, Geolode, and NLCD-style land cover sources that are useful for Northeast-heavy workflows.[cite:2] The AWS open geospatial dataset list also points to many directly accessible cloud-hosted objects, though individual dataset file URLs vary by bucket and product.[cite:41]

## Practical notes

For the most automation-friendly workflows, the easiest sources are Natural Earth, TIGER/Line, Geofabrik, GADM, NOAA GLOBE, and many USFS downloads because they expose stable direct file URLs or predictable path patterns.[cite:4][cite:5][cite:6][cite:7][cite:13][cite:30] ArcGIS Hub and state portals can still work well with `wget`, but they usually require one extra step to discover the final resource URL behind a dataset page.[cite:16] For northeastern U.S. production work, the highest-value combination is often TIGER/Line for admin units, Geofabrik for rich OSM vectors, Maine and New York state portals for local authoritative data, and USGS/NOAA/OpenTopography for terrain and imagery.[cite:2][cite:16][cite:24][cite:27]
